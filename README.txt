PASTOR DAVID BIRTHDAY TRIBUTE
==============================

HOW TO OPEN
1. Extract the ZIP file.
2. Open the pastor_david_birthday folder.
3. Double-click index.html (Chrome, Edge, Firefox, or another modern browser).

FILES
- index.html: page structure and birthday message
- style.css: responsive premium navy-and-gold design
- script.js: animations, fireworks, sound toggle, message copy, photo lightbox
- images/: the three supplied photos

CUSTOMIZATION
- Edit the birthday message in the message-body section of index.html.
- Replace images in the images folder, keeping the same filenames, to use different photos.
- Change colors at the top of style.css in the :root variables.
- The top-right music button opens the YouTube player for Dunsin Oyekan's 'Fragrance To Fire'. Click it again or close the player to stop playback. An internet connection is required, and browser/embed restrictions may affect playback.
- Google Fonts require internet access; system fallback fonts are provided.

NOTE
This is a static HTML/CSS/JavaScript site. It does not need a server or database.


Background music: The page attempts to start “Fragrance To Fire” by Dunsin Oyekan on load, then retries when the visitor first taps/clicks or presses a key. Chrome, Safari, and other browsers may block sound autoplay until that first interaction; this is a browser security policy, not something a website can override. Internet access is required.
